# Fact-check of ADR-0001 and ADR-0002 assumptions

- **Date:** 2026-09-29
- **Method:** web research against vendor documentation and changelogs. The proxy blocked direct fetches of developers.cloudflare.com, so the Cloudflare facts come from search-engine extracts of the cited official pages. Re-verify anything that becomes load-bearing.

| # | Claim | Verdict | Finding |
|---|---|---|---|
| 1 | AWS Snowball unavailable to new customers since late 2024 | **Corrected** | Nov 2024 retired Snowcone and older Snowball Edge models; Snowball Edge closed to new customers on **7 Nov 2025**. Conclusion unchanged. [AWS blog](https://aws.amazon.com/blogs/storage/aws-snow-device-updates), [FAQ](https://aws.amazon.com/snowball/faqs) |
| 2 | S3 egress ~$0.09/GB, 100 GB/month free | Verified | 10 TiB ≈ $920. [S3 pricing](https://aws.amazon.com/s3/pricing/) |
| 3 | R2 pricing, limits, presigned URLs, lifecycle | Verified, one caveat | $0.015/GB-month Standard; Class A $4.50/M, Class B $0.36/M; free egress. Max object ≈ 4.995 TiB; single PUT ≤ ~5 GiB; parts 5 MiB–5 GiB, ≤ 10,000 parts, all parts except the last equal in size. Presigned GET/HEAD/PUT/DELETE (no POST forms); presigned UploadPart works in practice but is not explicitly documented, so **spike it**. Event notifications to Queues are GA. Lifecycle rules support expiry by prefix; **incomplete multipart uploads are aborted after 7 days by default.** [limits](https://developers.cloudflare.com/r2/platform/limits/), [presigned](https://developers.cloudflare.com/r2/api/s3/presigned-urls/), [lifecycles](https://developers.cloudflare.com/r2/buckets/object-lifecycles/) |
| 4 | Homelab can pull from Queues over HTTP | Verified | Pull consumers with API token; up to 5,000 msg/s per queue. **Retention: 60 s–14 days (paid), 24 h on Free plan.** A homelab outage longer than that loses events, so a **reconciliation path is required** (list pending objects in D1/R2). [pull consumers](https://developers.cloudflare.com/queues/configuration/pull-consumers/), [limits](https://developers.cloudflare.com/queues/platform/limits/) |
| 5 | D1 or Durable Objects can hold the dedup index | Verified | Each capped at 10 GB; a few million rows ≈ hundreds of MB. Atomic claim via `INSERT … ON CONFLICT DO NOTHING` / conditional `UPDATE`; D1 is single-threaded per DB. [D1 limits](https://developers.cloudflare.com/d1/platform/limits/) |
| 6 | Email from Workers needs a third party | **Corrected** | **Cloudflare Email Service** sending is in public beta with a Workers binding; arbitrary recipients need the Workers Paid plan and an onboarded domain; 3,000 emails/month included. Resend and Postmark remain mature alternatives. [pricing](https://developers.cloudflare.com/email-service/platform/pricing/) |
| 7 | Google Play closed track; testing requirement; install referrer | Mostly verified, one addition | $25 one-time fee. Personal accounts created after 13 Nov 2023 need **12 testers for 14 days** before production. Closed track lists ≤ 2,000 emails; no time limit found, so permanent use looks viable (uncertain). **Developer verification** enforced from **30 Sep 2026** in BR/ID/SG/TH, globally in 2027; unregistered apps need a 24-hour "advanced flow" to sideload. **New: a free "limited distribution" account** (since Aug 2026) can distribute to **up to 20 authorized devices** without fee or ID. Install referrer through closed-track opt-in is **uncertain**; test on a device. [testing requirements](https://support.google.com/googleplay/android-developer/answer/14151465), [verification](https://android-developers.googleblog.com/2026/03/android-developer-verification-rolling-out-to-all-developers.html) |
| 8 | Windows: USB-copied exe avoids SmartScreen | Verified, **with a blocker** | MOTW lives in an NTFS alternate data stream; FAT32/exFAT sticks carry none, so SmartScreen does not prompt. **However, Smart App Control (Windows 11, on for clean installs) blocks unsigned, no-reputation executables regardless of MOTW, with no "Run anyway".** [SAC FAQ](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions), [MOTW](https://textslashplain.com/2016/04/04/downloads-and-the-mark-of-the-web/) |
| 9 | macOS: USB-copied app avoids Gatekeeper | Verified (security-research sources, not Apple docs) | Finder copies from USB don't set `com.apple.quarantine`; Gatekeeper evaluates only quarantined items. Sequoia removed the Control-click override. Apple Silicon requires at least ad-hoc signatures; **self-updated binaries must be re-signed ad hoc.** Test on real hardware. |
| 10 | Signing costs | Verified | Apple Developer $99/yr. **Azure Artifact Signing** (formerly Trusted Signing) Basic $9.99/month; **individuals only in the US or Canada**. This is the cheapest identity on which SAC/SmartScreen can build reputation. |
